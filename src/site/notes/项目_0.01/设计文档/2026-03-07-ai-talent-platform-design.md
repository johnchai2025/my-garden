# AI 人才识别与培养平台 - 产品设计文档

**创建日期**：2026-03-07
**版本**：v1.0
**状态**：设计阶段

---

## 一、产品愿景与使命

### 1.1 核心使命

在 AI 技术革命的浪潮中，帮助 99% 的普通人掌握 AI 应用能力，通过实践创造价值，成长为具备未来竞争力的"建造者"。

### 1.2 问题洞察

**当前困境**：
- 企业难以识别真正具备 AI 应用和构建能力的人才
- 传统招聘渠道无法有效展示候选人的实际 AI 能力
- 大部分普通人（99%）在 AI 浪潮中面临被边缘化的风险
- 精英化的 AI 社群（Reddit、GitHub 用户）形成了 1% 的壁垒
- 学生群体面临严峻就业压力，现有教育体系难以跟上技术变化

**目标群体的特点**：
- 对 AI 认知较低，使用停留在"聊天"层面
- 对 Agentic 工具缺乏经验，有畏难情绪
- 面临网络限制（VPN、API Key 等门槛）
- 有强烈的学习意愿和充裕的时间（尤其是学生群体）

### 1.3 解决方案

构建一个"草根性"的 AI 学习与展示平台，通过：
1. **零门槛培训**：使用国内可访问的工具，场景导向的实操教学
2. **成果展示**：学员的 AI 应用案例可见、可学习、可复现
3. **能力认证**：通过实际产出证明能力，而非简历和证书
4. **双向价值**：
   - 帮助普通人成长为"那 1%"
   - 为企业提供直观的人才识别渠道

### 1.4 差异化定位

**vs 精英化 AI 社群**：
- 我们服务 99% 的普通人，而非 1% 的技术精英
- 零技术门槛，使用国内工具（工具- IDE使用 Trae，模型调用Kimi、MiniMax、GLM等）
- 场景导向，解决真实生活和工作问题
- 中文环境，符合国内用户习惯

**vs 传统在线教育**：
- 不是"教知识"，而是"带实践"
- 交互式培训，边学边做
- 成果可见，形成作品集
- 社群驱动，持续成长

## 二、产品定位

### 2.1 产品名称
AI 实践案例库 / AI 应用工坊（待最终确定）

### 2.2 核心价值主张
帮助 AI 初学者通过真实场景实践，从"会聊天"到"会应用"，并通过案例展示获得认可和反馈。

### 2.3 目标用户

**主要用户**：大学生/研究生
- 面临就业压力，学习意愿强
- 时间充裕，可投入学习
- 需要提升就业竞争力
- 希望掌握面向未来的技能

**次要用户**：职场人士
- 希望通过 AI 提升工作效率
- 解决工作中的实际问题
- 探索职业转型机会

**潜在用户**：企业 HR / 决策者
- 寻找具备 AI 应用能力的人才
- 需要直观的能力展示渠道
- 不活跃在 GitHub/Reddit 等技术社区

## 三、核心功能设计

### 3.1 功能架构

```
平台核心
├── 案例库（核心）
│   ├── 场景分类
│   ├── 标签筛选
│   └── 案例详情
├── 培训系统
│   ├── 培训预告
│   ├── 报名入口
│   └── 录屏回放
├── 内容展示
│   ├── 首页
│   └── 关于我们
└── 社群入口
    └── "后 AI 时代"社群
```

### 3.2 首页设计

**目标**：3 秒内让访客理解平台价值

**内容结构**：
1. **Hero 区域**
   - 一句话价值主张："从 AI 使用者到 AI 建造者"
   - 副标题：零门槛学习 | 场景实战 | 成果展示
   - CTA 按钮：查看案例 / 报名培训

2. **使命宣言**
   - 简短阐述"服务 99% 普通人"的理念
   - 强调"草根性"和"实践导向"

3. **精选案例**
   - 3-6 个优质案例卡片
   - 展示不同场景（求职、论文、家庭教育等）
   - 封面图 + 标题 + 场景标签

4. **培训预告**
   - 下一期培训时间、主题
   - 报名入口

5. **数据展示**
   - 已有案例数
   - 学员数
   - 培训场次
   - （建立信任和社会证明）

6. **用户评价**
   - 学员反馈
   - 成长故事

### 3.3 案例库设计

#### 主导航：按场景分类
- 求职就业
- 论文调研与写作
- 家庭教育
- 投资理财
- 工作效率提升
- 其他创意应用

#### 筛选系统
**工具标签**：
- Trae
- Kimi
- MiniMax
- ChatGPT
- 其他

**前置条件标签**：
- 工具要求（需要 XX 账号、需要 API Key）
- 知识要求（需要了解 XX 概念）
- 资源要求（需要准备 XX 数据）

**时间投入**：
- <1 小时
- 1-3 小时
- >3 小时

#### 案例卡片
- 封面图（成果截图）
- 标题 + 一句话描述
- 场景标签 + 工具标签
- 作者信息
- 浏览数 / 收藏数（第二版）

### 3.4 案例详情页设计

**内容结构**：

1. **概述区**
   - 案例标题
   - 解决的问题（场景描述）
   - 最终成果展示（图片/视频/链接）
   - 作者信息 + 创建时间

2. **前置条件**
   - 需要的工具（带获取链接）
   - 需要的知识背景
   - 需要的资源准备
   - 预计时间投入

3. **实现步骤**
   - 分步骤详细教程（Markdown 格式）
   - 每步配图/代码/提示词
   - 关键点提示和注意事项

4. **培训录屏**
   - 嵌入视频（如果有对应的培训内容）
   - 时间戳导航

5. **互动区**（第二版功能）
   - 评论讨论
   - 收藏功能
   - "我也做了"（学员提交自己的实践版本）

### 3.5 培训页面设计

**培训列表**：
- 即将开始的培训（报名入口）
- 往期培训（观看录屏）

**培训详情**：
- 主题 + 场景
- 时间 + 平台（腾讯会议）
- 学习目标
- 前置准备
- 报名表单（姓名、联系方式、学习动机）

### 3.6 关于我们页面

**内容**：
- 平台使命（服务 99% 普通人）
- 核心理念（草根性、实践导向）
- 团队介绍
- 联系方式
- 加入社群（"后 AI 时代"社群入口）

## 四、用户旅程设计

### 4.1 新用户发现路径

```
小红书/公众号文章
  → 点击案例链接
  → 进入平台案例详情页
  → 浏览更多案例
  → 看到培训预告
  → 报名培训
```

### 4.2 学员成长路径

```
报名培训
  → 参加腾讯会议实操
  → 完成自己的案例
  → 提交到平台展示
  → 获得反馈和认可
  → 继续参加进阶培训
  → 成为"建造者"
```

### 4.3 商业转化漏斗

```
免费内容（案例库 + 基础培训）
  ↓
付费课程（系统化培训 + 项目指导）
  ↓
咨询服务（企业培训 + 定制方案）
```

### 4.4 企业用户路径

```
搜索/推荐发现平台
  → 浏览案例库
  → 发现优秀学员作品
  → 联系平台/学员
  → 招聘/合作
```

## 五、内容运营策略

### 5.1 案例库冷启动

**第一批案例来源**：
- 团队成员自己做的示范案例（10-15 个）
- 覆盖主要场景，展示不同复杂度
- 高质量、可复现、有实用价值

**案例质量标准**：
- 问题清晰、场景真实
- 步骤完整、可操作
- 成果可见、有价值
- 前置条件明确

### 5.2 培训内容规划

**基础系列**（免费）：
- AI 工具入门（Kimi、Trae 使用）
- 提示词基础与实践
- 场景实战：
  - 求职简历优化
  - 论文文献整理
  - 家庭教育方案设计
  - 投资信息分析

**进阶系列**（付费）：
- 复杂工作流设计
- 多工具组合应用
- 行业深度案例
- 项目实战指导

**培训原则**：
- 交互式：边讲边做，实时答疑
- 场景导向：解决真实具体的问题
- 成果导向：每次培训都要产出可见成果
- 零门槛：使用国内可访问的工具

### 5.3 引流渠道策略

#### 渠道 1：内部社群导流
- 利用现有"后 AI 时代"社群
- 设计实操简单课程
- 培训后将材料和录屏上传平台
- 形成社群 → 培训 → 平台的闭环

#### 渠道 2：针对学生群体
- 目标：大学生/研究生
- 痛点：就业压力大、前景不乐观
- 优势：学习意愿强、时间充裕
- 方式：通过腾讯会议线上培训
- 转化：培训 → 实践 → 案例展示 → 就业竞争力

#### 渠道 3：社交媒体内容生成

**小红书**：
- 案例拆解（图文形式）
- 工具测评对比
- 学员成果展示
- AI 应用技巧
- 频率：每周 2-3 篇

**微信公众号**：
- 深度教程文章
- 行业洞察分析
- 培训回顾总结
- 学员成长故事
- 频率：每周 1-2 篇

**内容复用策略**：
- 培训录屏 → 剪辑成短视频 → 小红书/视频号
- 案例教程 → 改写成图文 → 小红书/公众号
- 学员反馈 → 整理成案例 → 平台展示
- 平台案例 → 提炼要点 → 社交媒体内容

## 六、技术实现方案

### 6.1 技术栈选择

**前端**：
- Next.js 14（React 框架）
- TypeScript（类型安全）
- Tailwind CSS（快速样式开发）

**后端**：
- Next.js API Routes（无需单独后端）
- Supabase（BaaS 平台）

**数据库**：
- Supabase PostgreSQL

**文件存储**：
- Supabase Storage（图片、视频）

**认证系统**（第二版）：
- Supabase Auth

**部署**：
- Vercel（零配置部署，免费）

**域名**：
- 自定义域名

**优势**：
- 开发速度快
- 前期成本几乎为零
- 可扩展性强
- 维护成本低

### 6.2 数据模型设计

#### 案例表 (cases)
```sql
CREATE TABLE cases (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  title TEXT NOT NULL,
  description TEXT NOT NULL,
  category TEXT NOT NULL,
  cover_image TEXT,
  content TEXT NOT NULL,
  prerequisites JSONB,
  tools TEXT[],
  author_name TEXT NOT NULL,
  video_url TEXT,
  views INTEGER DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

**字段说明**：
- `prerequisites`：JSON 格式存储前置条件
  ```json
  {
    "tools": ["需要 Kimi 账号", "需要 Trae 安装"],
    "knowledge": ["了解基本提示词概念"],
    "resources": ["准备个人简历文档"],
    "time": "1-3小时"
  }
  ```
- `tools`：工具标签数组
- `content`：Markdown 格式的详细教程

#### 培训表 (trainings)
```sql
CREATE TABLE trainings (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  title TEXT NOT NULL,
  description TEXT NOT NULL,
  datetime TIMESTAMP NOT NULL,
  meeting_link TEXT,
  status TEXT DEFAULT 'upcoming',
  video_url TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);
```

**字段说明**：
- `status`：upcoming（即将开始）/ completed（已完成）
- `video_url`：培训录屏链接

## 七、运营节奏规划

### 7.1 第一个月：冷启动

**目标**：平台上线，完成第一批内容和用户积累

**关键任务**：
- 开发并上线平台（2-3 周）
- 发布 10-15 个示范案例
- 在"后 AI 时代"社群宣传
- 举办第一期免费培训（求职场景）
- 产出 3-5 篇小红书/公众号内容

**成功指标**：
- 平台上线
- 10+ 案例发布
- 第一期培训完成，20+ 学员参与
- 3-5 个学员案例产出

### 7.2 第二个月：验证

**目标**：验证核心假设，优化产品和内容

**关键任务**：
- 举办 2-3 期培训（不同场景）
- 收集学员案例，上传平台
- 持续内容输出（每周 3-4 篇）
- 收集用户反馈，优化平台体验
- 探索针对学生群体的宣传渠道

**成功指标**：
- 20+ 案例（含学员案例）
- 50+ 培训学员
- 小红书/公众号粉丝增长
- 用户反馈积极

### 7.3 第三个月：扩展

**目标**：扩大规模，探索商业化

**关键任务**：
- 开发用户系统（注册/登录）
- 开放学员提交案例功能
- 设计并推出第一个付费课程
- 扩大宣传渠道（针对大学生群体）
- 建立案例审核和质量标准

**成功指标**：
- 50+ 案例
- 100+ 注册用户
- 第一个付费课程上线
- 初步商业化验证

## 九、风险与应对

### 9.1 内容质量风险

**风险**：学员提交的案例质量参差不齐

**应对**：
- 建立案例审核机制
- 提供案例模板和质量标准
- 培训中强调成果导向
- 初期由团队策展，逐步开放

### 9.2 用户留存风险

**风险**：用户参加一次培训后流失

**应对**：
- 设计进阶学习路径
- 建立社群归属感
- 定期举办活动和挑战
- 展示学员成长故事

### 9.3 竞争风险

**风险**：市场上出现类似平台

**应对**：
- 强化"草根性"和"99% 普通人"的定位
- 深耕场景，提供真实价值
- 建立社群壁垒
- 持续内容和服务创新

### 9.4 技术门槛风险

**风险**：即使是国内工具，部分用户仍觉得门槛高

**应对**：
- 提供详细的工具安装和使用教程
- 培训中手把手指导
- 建立互助社群
- 持续降低使用门槛

## 十一、总结

这个平台不仅仅是一个技术产品，更是一个社会使命驱动的项目。我们希望通过：

1. **降低门槛**：让 99% 的普通人都能学会 AI
2. **实践导向**：通过真实场景产出有价值的成果
3. **成果展示**：让能力可见，打破信息壁垒
4. **持续成长**：从使用者到建造者的转变

最终目标是帮助更多普通人，尤其是年轻一代，在 AI 时代不被边缘化，而是成为具备未来竞争力的"建造者"。

同时，为企业和社会提供一个直观、有效的人才识别渠道，推动整个社会在 AI 时代的进步。
