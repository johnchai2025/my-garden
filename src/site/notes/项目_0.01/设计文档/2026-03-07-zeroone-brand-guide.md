# 零一 (Zero One) 品牌指南

**创建日期**：2026-03-07
**版本**：v1.0

---

## 一、品牌核心

### 1.1 品牌名称

**中文名称**：零一
**英文名称**：Zero One
**品牌符号**：0.01
**读音**：líng yī

### 1.2 品牌含义

**"零"的含义**：
- 零门槛：任何人都可以开始
- 从零开始：不需要技术背景
- 归零心态：放下过去，拥抱新技术

**"一"的含义**：
- 成为那 1%：从 99% 突破到 1%
- 第一步：迈出改变的第一步
- 唯一性：每个人都是独特的建造者

**"0.01"的含义**：
- 数字化表达，符合 AI 时代
- 精确、科技、未来感
- 从 0 到 1 的过程（0.01 是关键节点）

### 1.3 品牌使命

帮助 99% 的普通人掌握 AI 应用能力，通过实践创造价值，成为 AI 时代的 1% Navigators。

### 1.4 品牌定位

**目标用户**：99% 的普通人（尤其是学生群体）
**核心价值**：零门槛、场景实战、成果展示
**差异化**：草根性、实践导向、中文环境

### 1.5 品牌 Slogan

**主 Slogan**：从 99% 到 1% 的 AI Navigators

**备选 Slogan**：
- 每个人都能成为那 1%
- 零门槛，一起成为 AI Navigators
- 从零开始，成为那 0.01

## 二、视觉识别系统

### 2.1 Logo 设计

#### 主 Logo（中文版）
```
┌─────────────┐
│   零  一    │
│   ─────     │
│  0.01       │
└─────────────┘
```

**设计说明**：
- 中文"零一"为主体，字体简洁现代
- 下方 0.01 为辅助，强化数字符号
- 中间横线连接，象征从 0 到 1 的桥梁

#### 副 Logo（英文版）
```
┌─────────────┐
│ ZERO ONE    │
│   ─────     │
│  0.01       │
└─────────────┘
```

#### 符号 Logo（简化版）
```
┌─────┐
│ 0.1 │
└─────┘
```

**使用场景**：
- 主 Logo：官网、公众号、正式场合
- 副 Logo：国际化场景、英文内容
- 符号 Logo：小红书头像、App 图标、水印

### 2.2 品牌色彩

#### 主色调
**深空蓝** (Deep Space Blue)
- HEX: #0A1929
- RGB: 10, 25, 41
- 象征：技术、未来、深度

**突破橙** (Breakthrough Orange)
- HEX: #FF6B35
- RGB: 255, 107, 53
- 象征：突破、活力、从 99% 到 1%

#### 辅助色
**科技灰** (Tech Gray)
- HEX: #64748B
- RGB: 100, 116, 139
- 用途：文字、边框、背景

**纯白** (Pure White)
- HEX: #FFFFFF
- RGB: 255, 255, 255
- 用途：背景、文字

**成功绿** (Success Green)
- HEX: #10B981
- RGB: 16, 185, 129
- 用途：成功状态、完成标记

### 2.3 字体系统

#### 中文字体
**标题字体**：思源黑体 Bold / 阿里巴巴普惠体 Bold
**正文字体**：思源黑体 Regular / 苹方 Regular

#### 英文/数字字体
**标题字体**：Inter Bold / SF Pro Display Bold
**正文字体**：Inter Regular / SF Pro Text Regular
**代码字体**：JetBrains Mono / Fira Code

### 2.4 视觉风格

**设计原则**：
- 简洁：去除不必要的装饰
- 现代：符合 2026 年审美
- 科技：体现 AI 时代特征
- 温暖：不冷冰冰，有人文关怀

**视觉元素**：
- 网格和线条（象征结构和连接）
- 渐变色（象征从 0 到 1 的过渡）
- 圆角矩形（现代、友好）
- 数字和代码元素（科技感）

## 四、品牌语言

### 4.1 语言风格

**核心原则**：
- 平实：不用高深术语，说人话
- 鼓励：传递正能量，激发信心
- 真诚：不夸大，不割韭菜
- 行动：强调实践，而非理论

### 4.2 常用话术

**欢迎语**：
- "欢迎来到零一，从这里开始成为 AI Navigator"
- "零门槛学 AI，一起成为那 1%"

**鼓励语**：
- "每个人都能成为那 1%"
- "从零开始，没有什么不可能"
- "你的第一个 AI 项目，从这里开始"

**行动号召**：
- "立即开始实践"
- "报名免费培训"
- "查看更多案例"
- "提交你的作品"

### 4.3 禁用词汇

**避免使用**：
- 精英、高端、顶尖（与草根定位冲突）
- 保证、必然、一定（避免过度承诺）
- 割韭菜、收智商税（负面联想）
- 复杂的技术术语（降低门槛）

## 六、品牌故事

### 6.1 创始故事

> 在 AI 技术革命的浪潮中，我们看到了一个残酷的现实：
>
> 1% 的人掌握了 AI 技术，活跃在 GitHub、Reddit 等技术社区，成为这个时代的先行者。
>
> 而 99% 的普通人，尤其是面临就业压力的学生群体，在这场变革中感到迷茫和焦虑。他们想学 AI，但面临重重障碍：需要 VPN、需要 API Key、需要技术背景、需要英文能力...
>
> 我们不甘心看到这样的分化。
>
> 我们相信，每个普通人都有成为那 1% 的潜力。关键是要有一座桥梁，一个零门槛的起点。
>
> 于是，零一诞生了。
>
> "零"代表零门槛、从零开始、归零心态。
> "一"代表成为那 1%、迈出第一步、每个人的唯一性。
>
> 我们不是精英俱乐部，而是 99% 通往 1% 的桥梁。
>
> 我们用国内可访问的工具，教真实场景的应用，让每个人都能产出有价值的成果。
>
> 从零开始，成为那 0.01 的 AI Navigators。
>
> 这就是零一。

### 6.2 用户故事模板

**标题**：从 [身份] 到 AI Navigator：[姓名] 的零一之旅

**结构**：
1. 起点：我是谁，遇到什么问题
2. 转折：在零一学到了什么
3. 成果：做出了什么项目
4. 改变：对我的影响
5. 展望：下一步计划

**示例**：
> 我是一名大四学生，投了 50 份简历都石沉大海。
>
> 在零一的第一期培训中，我学会了用 Kimi 优化简历。
>
> 我用 AI 分析了目标岗位的 JD，重新组织了简历内容，突出了相关经验。
>
> 结果，我拿到了 3 个面试机会，最终成功入职。
>
> 现在，我继续在零一学习，用 AI 提升工作效率。我相信，我已经成为了那 1%。
